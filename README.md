# Smart Partial Weight-Bearing Monitoring System

## Overview
A smart rehabilitation monitoring system designed to assist post-orthopaedic patients by monitoring partial weight-bearing during recovery.

## Features
- Real-time weight monitoring
- Pressure sensing
- Rehabilitation feedback
- Data collection and analysis

## Technologies Used
- Arduino
- Embedded Programming
- Sensors
- CAD Design
- ANSYS Simulation

## Project Structure
- Code/
- CAD/
- Simulations/
- Documentation/

## Project Purpose
This project was developed to support rehabilitation monitoring and improve patient recovery feedback through smart sensing technology.
